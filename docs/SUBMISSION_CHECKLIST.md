# Open Agent Hackathon Submission Checklist

## Product
- [ ] Target user, initial question, and scope match `PRODUCT_DEFINITION.md`.
- [ ] Full workflow from investigation to dossier is demonstrated.
- [ ] Evidence status is deterministic and explained.
- [ ] Synthetic fixtures are visibly labelled and not presented as real evidence.
- [ ] Known limitations and next actions are shown.

## Sponsor integrations
- [ ] Zetaris official endpoint/auth/request format verified.
- [ ] Real Zetaris query returns a relevant usable record.
- [ ] Meterless required capability identified and a real operation shown.
- [ ] Nemotron model route and actual model identity independently verified.
- [ ] H-MEM integration claimed only if actual official implementation is tested.
- [ ] All proof is redacted; no secrets in repository or video.

## Engineering
- [ ] `npm ci` or `npm install` succeeds from a clean checkout.
- [ ] `npm run build` passes.
- [ ] `npm test` passes.
- [ ] `npm run check` passes.
- [ ] Setup instructions tested from a clean environment.
- [ ] `.env` and secrets are excluded from Git.
- [ ] Failure/partial-result behavior tested.
- [ ] Repo includes source, README, architecture, test instructions, dependencies, and integration docs.

## Eligibility and process
- [ ] Read current official rules and submission requirements.
- [ ] Check build-window/pre-existing-code rules.
- [ ] Disclose reused/pre-existing components truthfully.
- [ ] Record actual Cursor use in `CURSOR_BUILD_LOG.md`.
- [ ] Ensure team size and track selection comply with official rules.

## Submission artifacts
- [ ] 1–4 minute demo video recorded.
- [ ] Slide deck completed from the supplied template.
- [ ] Repository link is public/accessibly shared as required.
- [ ] README setup and use instructions work.
- [ ] Sponsor integration proof is linked/documented.
- [ ] All claims in the deck are demonstrated and accurate.
