# Release Notes

## 1.0.0 — Product foundation
- Consolidated Nexus product definition and requirements around Kenyan agricultural market intelligence.
- Added typed evidence and decision contracts.
- Added local investigation history and dossier retrieval routes.
- Added generic Zetaris and Meterless Runtime adapters with explicit unverified/fallback behavior.
- Added deterministic evidence checklist and tests.
- Added product, architecture, data dictionary, security, testing, integration, demo, and submission documentation.
- Kept H-MEM disabled pending verification of the actual official API.

This version is a hackathon prototype foundation. It is not a production agricultural advisory service and does not claim sponsor integrations are complete.
